# 打败晚睡大魔王 - Oliver的睡前冒险

## 游戏简介
一个专为 Oliver（5岁）设计的趣味睡前任务管理 H5 游戏。通过完成任务获取buff力量，最终打败晚睡大魔王！

## 使用方法
直接用浏览器打开 `index.html` 即可游玩。

## 游戏流程

### 1. 开始冒险
点击"开始冒险！"按钮进入游戏。

### 2. 添加任务（家长操作）
点击底部的 "+ 添加任务" 按钮，选择今晚需要完成的任务：
- 洗澡 (水之力量 +25)
- 刷牙 (闪光力量 +20)
- 读英语 (英语魔力 +30)
- 读绘本 (故事之力 +25)
- 换睡衣 (盔甲之力 +15)
- 上厕所 (轻盈之力 +15)
- 喝水 (生命之水 +15)
- 拥抱 (爱的力量 +20)
- 收拾玩具 (整理之力 +25)
- 伸懒腰 (伸展之力 +15)

也可以自定义任务名称。

### 3. 完成任务（Oliver操作）
每完成一个任务，点击对应的"完成"按钮：
- 获得对应的buff力量
- 屏幕弹出buff效果
- 任务卡片变成绿色并显示✅

### 4. 战斗！
所有任务完成后（或选择跳过部分任务后），点击"战斗！"按钮：
- 每个已完成的任务变成一个攻击技能
- 如果全部完成，还可以使用"终极一击"（双倍伤害）
- 跳过任务会让大魔王变得更强大

### 5. 胜利/失败
- **胜利**：打败大魔王，显示庆祝动画和统计
- **失败**：大魔王嘲笑你，鼓励明天更努力

## 设计理念
- 5岁孩子对抽象时间没有概念，但对"打怪升级"有天然理解
- 每个睡前任务 = 一个buff = 一份力量
- 完成所有任务 = 满buff = 轻松打败大魔王
- 跳过任务 = 力量不够 = 打不过大魔王
- 通过游戏化的方式，让Oliver主动完成任务

## 技术特点
- 纯HTML/CSS/JS，无需服务器，双击即用
- 像素风角色和怪物（Canvas绘制）
- Web Audio API 生成音效
- 手机/平板自适应
- 离线可玩，无需网络
